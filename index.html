Music Genre Classification using Machine Learning

I explored a simplified approach to classifying music genres using the means and variances of Mel-Frequency Cepstral Coefficients (MFCCs). This project compares the performance of Random Forest Classifiers, CNNs, and LSTMs on a dataset of Rock, Electronic, Folk, and Classical music.

Capstone Project: Bipedal Locomotion using Reinforcement Learning

This research explores the implementation of a reinforcement learning framework using the Unity engine and ML-Agents Toolkit to train a bipedal humanoid using a reward function and Proximal Policy Optimization (PPO) algorithm. This project finds emergent behaviors, such as shuffling and extreme leaning, to demonstrate how agents exploit physics engines to find local optima rather than natural locomotion.
